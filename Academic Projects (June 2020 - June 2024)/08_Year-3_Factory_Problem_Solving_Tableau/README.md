# Factory problem-solving dashboards

**Year 3 · Business Intelligence · Tableau, dashboard design**

## Primary evidence and code status

[`script/Project BI.twbx`](script/Project%20BI.twbx) is the original packaged Tableau workbook. `report/presentation.pdf` and `report/mockup_dashboard.pdf` document the project and design. No complete dashboard PNG export is present.

## Dataset and workflow

`dataset/chrimp update.csv` is the supplied CPF factory data used to examine operational issues, including inventory discrepancies. The workbook contains the calculations, visualisations, filters and **five dashboards**.

## End-to-end workflow

Use the supplied CSV → analyse factory patterns in Tableau → build interactive dashboard views → present the findings and design mockups. Viewing or exporting the final dashboards requires Tableau.

## Results and outcome

Five dashboards were delivered for inspecting factory patterns. A measured improvement in factory operations was not verified in the recovered files.

## Saved historical results

The interactive views remain inside the `.twbx` workbook. `report/mockup_dashboard.pdf` shows design mockups, **not exports of the final dashboards**. [`result/README.md`](result/README.md) explains the missing PNG exports.
